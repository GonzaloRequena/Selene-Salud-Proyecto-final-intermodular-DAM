⚙️ ¿Cómo funciona la generación automática de turnos?

Cuando pulsas el botón, el backend toma tu rango horario completo y realiza una segmentación matemática automática en la base de datos de Neon.

  • Protección de Identidad: La API inyecta tu ID de usuario de forma segura mediante el token. No puedes suplantar el horario de otro médico.
  • Mapeo de Intervalos: Si abres de 09:00 a 10:00 con intervalos de 15 minutos, el sistema generará automáticamente 4 huecos independientes listos para que los pacientes los reserven desde la aplicación móvil.
  • Centros Asignados: Solo aparecen en tu lista los centros médicos con los que el Administrador te ha vinculado formalmente desde el panel global.
